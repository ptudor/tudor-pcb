Tudor PCB 1.2 is localized into 83 languages. Every menu, panel, alert,
history record, color-proof label, and fabrication diagnostic follows the
language order in System Settings, in the app and in the GerberKit parsing
library it is built on.

## Downloads

- `TudorPCB-1.2.0-macos-universal.dmg`: installer with an Applications shortcut.
- `TudorPCB-1.2.0-macos-universal.zip`: the app for Apple silicon and Intel Macs, macOS 14 or later.
- `TudorPCB-1.2.0-macos-universal.dSYM.zip`: debug symbols matching the shipped executable.
- `TudorPCB-1.2.0-macos-universal.notarization.json`: accepted Apple submission IDs and final package hashes.
- `checksums.txt`: SHA-256 manifest for the release assets.

Open the installer or expand the app ZIP, then move Tudor PCB to Applications.
The app and installer are Developer ID signed, notarized by Apple, and carry
stapled notarization tickets. The app runs in the App Sandbox and reads only
the files and folders you select.

Counts follow each language's plural rules, and numbers and dates follow the
system region format. Product and format names (KiCad, Altium, EasyEDA, Eagle,
JLCPCB, Gerber, RS-274X, Excellon) and Gerber attribute names such as
`FileFunction` stay as written in every language. To run Tudor PCB in a
language other than the system language, add it under System Settings →
General → Language & Region → Applications.

## Changes since 1.0.0

- Every user-facing string in the app and in GerberKit lives in a String
  Catalog with a translator comment, so translations are maintained beside
  the code and checked by the test suite.
- GerberKit localizes its own resource bundle: parse reasons, import warnings,
  limit errors, and layer names read in the host's language, and the Finder
  document type names are localized too.
- `BoardDocument.warnings` is now the sum of `importWarnings` and
  `proofWarnings`, with the proof warnings derived from the proof state
  instead of matched by English prefix.
- Release publication tolerates GitHub's release-listing lag and publishes the
  draft by release id.

## Limits

The "Browse N Recent Packages" button has no Lao translation yet and appears
in English in that language. EasyEDA `.FCTS` and `.FCBS` color silkscreen
payloads remain encrypted for JLCPCB and are rendered as a labeled fallback;
the other limits of 1.0 are unchanged.

The source is available under the MIT license, and the license text is
bundled inside the app. Published artifacts include checksums and GitHub
build attestations.
Attestations identify the build source; Apple signatures and notarization are
verified separately. See the repository's `docs/releases.md` for verification.
